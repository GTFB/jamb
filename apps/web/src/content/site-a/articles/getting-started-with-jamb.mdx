# Getting Started with Jamb

Jamb is a modern content management system built with Next.js and TypeScript. It uses Git as a CMS, making it perfect for developers who want full control over their content.

## Features

- **Git-based CMS**: All content is stored in Git, making it easy to version control and collaborate
- **TypeScript**: Full TypeScript support for type-safe content
- **Next.js**: Built on Next.js for optimal performance
- **MDX Support**: Write content in MDX for rich, interactive content

## Getting Started

1. Clone the repository
2. Install dependencies
3. Start the development server
4. Create your first content
